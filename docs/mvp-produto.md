# MVP — Portfólio Orlando Namba

> Fonte: `pf-po` (2026-08-10). Decisões do Orlando aplicadas.

## Proposta de valor

**Orlando Namba** é desenvolvedor **full-stack** que entrega produtos web de ponta a ponta. Aberto a **vagas** e **freelas**. O site responde em &lt;30s: *quem é, o que já fez, como falar com ele*.

## Público

| Prioridade | Público | Job-to-be-done |
|------------|---------|----------------|
| P1 | Recrutadores / tech leads | Stack, maturidade (demos), se vale contato |
| P1 | Clientes freela | Se entrega site/app útil e como contratar (WhatsApp) |
| P2 | Peers | Credibilidade — não otimizar MVP para isso |

## Escopo MVP (Must)

Landing single-page, só PT, light + toggle dark, deploy tipo Vercel (sem domínio próprio).

| Seção | Entrega |
|-------|---------|
| Hero | Marca dominante; headline full-stack / vagas+freelas; CTAs Contato + Projetos |
| Sobre | ADS em curso, posicionamento verdadeiro |
| Projetos | 2 cases: URL ao vivo + preview capturado; sem link de repo |
| Skills | Skills reais do contexto — sem inflar |
| Contato | WhatsApp, e-mail, LinkedIn (GitHub/Instagram secundários) |

### Projetos

1. Disparo Inteligente — https://disparointeligente.app.br
2. Igreja do Nazareno São Bernardo Central — https://nazarenosaobernardocentral.netlify.app/

## Fora de escopo (fase 2)

Formulário server-side, domínio próprio, blog/CMS, i18n, cases sem URL pública, analytics avançado.

## Contato

**MVP = links apenas** (WhatsApp + e-mail + LinkedIn). Sem `pf-backend` no caminho crítico.

## Critérios de sucesso (go-live)

- ≤10s: nome, papel, abertura vaga/freela
- 2 demos abrem; previews batem com o produto
- Contatos em 1 clique; default light + dark ok
- Sem conteúdo inventado; sem links mortos
